# Credit-Card-Classification

**Goal:** Predict if customer will default next month.

**Tech Stack:** Python (Random Forest) + PowerBI

**Results:**
- Model Accuracy: 81% (on 30% test data)
- Default Rate: 22%
- Key Insight: <50K credit limit group has 32% default rate (highest risk), 500K+ has 11% (lowest)

**Dashboard:** 2 KPI cards + Default Rate by Limit Group

**Business Impact:** Bank can flag <50K customers for early follow-up to reduce NPA.
